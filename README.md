# פסקול הזמן

משחק בסגנון היטסטר עם שירים ישראליים. סורקים קלף, שומעים קטע מהשיר ומנחשים באיזו שנה הוא יצא.

| קובץ | מה הוא עושה |
|---|---|
| `songs.csv` | **רשימת השירים. כל השינויים נעשים רק כאן.** |
| `songs.js` | טוען את הרשימה. בראש הקובץ יש הגדרות: אורך הקטע ומספר השניות שמוסיף הכפתור "+". |
| `index.html` | הנגן. הקלפים מפנים אליו. |
| `cards.html` | מפיק את הקלפים להדפסה ישירות מ-`songs.csv`. |
| `index.html#test` | בודק שכל סרטוני היוטיוב עובדים. **העמוד מציג את כל התשובות.** |

## איך משנים שירים

עורכים את `songs.csv`: ב-GitHub לוחצים על הקובץ ואז על ✏️, או פותחים אותו באקסל.

| עמודה | הסבר |
|---|---|
| מספר קלף | מספר ייחודי. זה המספר ש-QR מפנה אליו. |
| שנה | מה שמודפס על גב הקלף. |
| שם השיר, מבצע | גם הם מודפסים על גב הקלף. |
| קישורי יוטיוב | קישור מלא או מזהה הסרטון בלבד. אפשר לשים כמה קישורים מופרדים ברווח. אם הראשון חסום, הנגן עובר לבא אחריו. |
| שנייה להתחלה | לא חובה. אם משאירים ריק, הקטע מתחיל ב-20% מאורך השיר, לכל המאוחר בשנייה 30. |

- **להחליף שיר בקלף שכבר הודפס:** משנים את השורה ומשאירים את מספר הקלף. ה-QR ימשיך לעבוד, אבל צריך להדפיס מחדש את הגב של הקלף.
- **להוסיף שיר:** מוסיפים שורה עם מספר חדש, למשל 101. בעמוד `cards.html` כותבים 101 בשדה "רק קלפים מספר" ומדפיסים.
- **לשמור מאקסל:** שומרים בפורמט CSV רגיל או CSV UTF-8. שני הקידודים נתמכים.

האתר מתעדכן לבד דקה או שתיים אחרי השמירה.
